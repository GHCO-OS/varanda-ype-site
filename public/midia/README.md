# Banco de imagens Varanda Ypê

Este diretório guarda imagens reais do restaurante para uso no site, delivery, SEO local e campanhas.

## Estrutura

- `originais/`: arquivos recebidos, preservados em alta qualidade.
- `otimizadas/`: versões leves para publicar no site.
- `catalogo-imagens.json`: índice público com nome, categoria, disponibilidade, descrição, alt text e caminhos.

## Padrão de nome

Use nomes descritivos, sem acentos, com contexto local e ano:

```text
frango-a-milanesa-delivery-varanda-ype-campinas-2026.jpg
frango-a-milanesa-delivery-varanda-ype-campinas-2026.webp
```

## Disponibilidade

- `fixo`: disponível todos os dias.
- `rotativo`: depende do cardápio do dia.

Itens fixos informados neste lote: frango grelhado, frango à milanesa, peixe frito, omelete e lombo suíno.
